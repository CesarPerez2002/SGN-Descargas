Qué incluye la versión 1.1

  • Punto de Venta con factura numerada automáticamente (FAC-000001, FAC-000002, ...).
  • Elección entre Comprador final y cliente guardado.
  • Carrito multiproducto, total automático y descuento de stock.
  • Compras con proveedor, factura y suma al inventario.
  • Menú según el documento del proyecto: Inicio, Compras, Inventario, Clientes, Proveedores y Usuarios y Seguridad.
  • Acceso con usuario o correo: admin / admin@sgn.local, clave Admin2026!.

Si desinstalas el sistema, la base de datos se conserva para no perder información.
